# ModelHarbor-Agent

ยินดีต้อนรับสู่ ModelHarbor-Agent ตัวแทน AI ที่ทรงพลังสำหรับนักพัฒนา

## เกี่ยวกับ

ModelHarbor-Agent เป็นส่วนขยายของ Visual Studio Code ที่ใช้ AI เพื่อช่วยนักพัฒนาในการเขียนโค้ด ทำความเข้าใจฐานข้อมูลโค้ด และเพิ่มประสิทธิภาพเวิร์กโฟลว์การพัฒนา

## คุณสมบัติหลัก

- การนำทางฐานข้อมูลโค้ดด้วย AI
- การค้นหาโค้ดอย่างชาญฉลาด
- การสนับสนุนการพัฒนาหลายโมเดล
- การรวมเครื่องมือที่ปรับแต่งได้
- การสนับสนุนหลายภาษา

## การติดตั้ง

1. เปิด Visual Studio Code
2. ไปที่แท็บส่วนขยาย
3. ค้นหา "ModelHarbor-Agent"
4. คลิกติดตั้ง

## การใช้งาน

หลังจากติดตั้ง คุณสามารถเริ่มใช้งาน ModelHarbor-Agent ได้โดย:

- กด `Ctrl+Shift+P` เพื่อเปิดพาเลทคำสั่ง
- พิมพ์ "ModelHarbor" เพื่อดูคำสั่งทั้งหมด
- เลือกคำสั่งที่ต้องการ
