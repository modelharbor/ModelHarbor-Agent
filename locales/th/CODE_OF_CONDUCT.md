# หลักปฏิบัติของผู้มีส่วนร่วม

## คำมั่นสัญญาของเรา

เพื่อสร้างสภาพแวดล้อมที่เปิดกว้างและต้อนรับ เราในฐานะผู้มีส่วนร่วมและผู้ดูแล
มุ่งมั่นที่จะทำให้การมีส่วนร่วมในโครงการและชุมชนของเรา
เป็นประสบการณ์ที่ปราศจากการล่วงละเมิดสำหรับทุกคน ไม่ว่าจะเป็นอายุ ขนาดร่างกาย
ความพิการ เชื้อชาติ ลักษณะทางเพศ อัตลักษณ์และการแสดงออกทางเพศ
ระดับประสบการณ์ การศึกษา สถานะทางเศรษฐกิจสังคม สัญชาติ ลักษณะภายนอก
เชื้อชาติ ศาสนา หรืออัตลักษณ์และรสนิยมทางเพศ

## มาตรฐานของเรา

ตัวอย่างพฤติกรรมที่มีส่วนช่วยสร้างสภาพแวดล้อมเชิงบวก
ได้แก่:

- ใช้ภาษาที่ต้อนรับและครอบคลุม
- เคารพในมุมมองและประสบการณ์ที่แตกต่าง
- ยอมรับคำวิจารณ์เชิงสร้างสรรค์อย่างสง่างาม
- มุ่งเน้นสิ่งที่ดีที่สุดสำหรับชุมชน
- แสดงความเห็นอกเห็นใจต่อสมาชิกชุมชนคนอื่นๆ

ตัวอย่างพฤติกรรมที่ไม่สามารถยอมรับได้ของผู้เข้าร่วม ได้แก่:

- การใช้ภาษาหรือภาพลามกและการล่วงละเมิดทางเพศที่ไม่พึงประสงค์ หรือการเกี้ยวพาราสี
- การยั่วยุ คำติชมดูหมิ่น และการโจมตีส่วนบุคคลหรือการเมือง
- การล่วงละเมิดต่อสาธารณะหรือส่วนตัว
- การเผยแพร่ข้อมูลส่วนตัวของผู้อื่น เช่น ที่อยู่ทางกายภาพหรืออิเล็กทรอนิกส์
  โดยไม่ได้รับอนุญาตอย่างชัดเจน
- พฤติกรรมอื่นๆ ที่อาจถือได้ว่าไม่เหมาะสมในสภาพแวดล้อมการทำงาน

## ความรับผิดชอบของเรา

ผู้ดูแลโครงการมีหน้าที่ในการชี้แจงมาตรฐานของพฤติกรรมที่ยอมรับได้
และคาดหวังให้ดำเนินการแก้ไขที่เหมาะสมและยุติธรรม
เพื่อตอบสนองต่อกรณีพฤติกรรมที่ไม่สามารถยอมรับได้

ผู้ดูแลโครงการมีสิทธิ์และความรับผิดชอบในการลบ แก้ไข หรือ
ปฏิเสธความคิดเห็น การคอมมิต โค้ด การแก้ไขวิกิ ปัญหา และการมีส่วนร่วมอื่นๆ
ที่ไม่สอดคล้องกับหลักปฏิบัตินี้ หรือแบนชั่วคราวหรือ
ถาวรผู้มีส่วนร่วมใดๆ สำหรับพฤติกรรมอื่นๆ ที่พวกเขาเห็นว่าไม่เหมาะสม
ข่มขู่ ไม่สุภาพ หรือเป็นอันตราย

## ขอบเขต

หลักปฏิบัตินี้ใช้ทั้งในพื้นที่โครงการและในพื้นที่สาธารณะ
เมื่อบุคคลเป็นตัวแทนของโครงการหรือชุมชน ตัวอย่างของ
การเป็นตัวแทนโครงการหรือชุมชน ได้แก่ การใช้อีเมลโครงการอย่างเป็นทางการ
การโพสต์ผ่านบัญชีสื่อสังคมออนไลน์ทางการ หรือการทำหน้าที่เป็นตัวแทนที่ได้รับการแต่งตั้ง
ในกิจกรรมออนไลน์หรือออฟไลน์ การเป็นตัวแทนของโครงการอาจจะ
ถูกกำหนดและชี้แจงเพิ่มเติมโดยผู้ดูแลโครงการ

## การบังคับใช้

กรณีของพฤติกรรมการละเมิด การล่วงละเมิด หรือพฤติกรรมที่ไม่สามารถยอมรับได้อื่นๆ อาจ
รายงานได้โดยติดต่อทีมโครงการที่ support@roocode.com ข้อร้องเรียนทั้งหมด
จะได้รับการตรวจสอบและสอบสวน และจะส่งผลให้เกิดการตอบสนองที่
เห็นว่าจำเป็นและเหมาะสมกับสถานการณ์ ทีมโครงการมี
ภาระผูกพันในการรักษาความลับเกี่ยวกับผู้รายงานเหตุการณ์
รายละเอียดเพิ่มเติมของนโยบายการบังคับใช้เฉพาะอาจถูกโพสต์แยกต่างหาก

ผู้ดูแลโครงการที่ไม่ปฏิบัติตามหรือบังคับใช้หลักปฏิบัตินี้อย่าง
สุจริตอาจเผชิญกับผลกระทบชั่วคราวหรือถาวรตามที่กำหนดโดย
สมาชิกคนอื่นๆ ของผู้นำโครงการ
